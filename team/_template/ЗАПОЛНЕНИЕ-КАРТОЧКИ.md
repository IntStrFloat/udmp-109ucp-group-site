# Как заполнить свою карточку

Карточка живёт в вашей папке `team/<фамилия>/index.html`.
Всё оформление уже подключено — нужно только подставить свои данные.

## Шаг 1. Создайте папку

Скопируйте папку `team/_template` целиком и назовите копию своей фамилией
латиницей: `team/ivanov`.

## Шаг 2. Заполните анкету

Откройте `team/ivanov/index.html` и найдите в конце файла блок:

```html
<script type="application/json" data-student>
```

Заполните поля:

| Поле       | Что писать |
|------------|------------|
| `name`     | Фамилия и имя, как хотите показываться на сайте |
| `role`     | Роль или специализация, например «Backend-разработчик» |
| `photo`    | Путь к фото **от корня сайта**, например `team/ivanov/photo.jpg`. Нет фото — оставьте `""`, покажутся инициалы |
| `about`    | Несколько предложений о себе. Абзацы разделяйте `\n\n` |
| `skills`   | Список навыков: каждый в кавычках, через запятую |
| `contacts` | `email`, `telegram`, `github`, `phone` — любые из них. Лишние удалите, свои добавьте: незнакомое ключу имя станет подписью |

Это формат JSON: кавычки, запятые и фигурные скобки обязательны.
Если ошиблись — страница сама подскажет, что именно не так.

## Шаг 3. Добавьте фото (по желанию)

Положите файл рядом со своей страницей: `team/ivanov/photo.jpg`,
а в анкете укажите `"photo": "team/ivanov/photo.jpg"`.

## Шаг 4. Свободный HTML (по желанию)

В шаблоне есть зона:

```html
<div class="free"> ... </div>
```

Пишите внутри обычные теги: `<h2>`, `<p>`, `<ul>`, `<img>`, `<a>` —
оформление уже задано. Зона не нужна — удалите весь `<div>`.

## Шаг 5. Полный контроль (по желанию)

В `<head>` шаблона есть два помеченных слота:

- свои стили: `<link rel="stylesheet" href="style.css">`;
- свои скрипты и библиотеки: например jQuery с CDN.

Можно переписать страницу целиком. Главное — оставьте
`<meta name="site-root">` и подключение общих стилей, если хотите
сохранить единые шапку и подвал сайта.

## Шаг 6. Добавьте себя в состав

Откройте `assets/js/roster.js` и допишите строку по образцу:

```js
{
  slug: "ivanov",
  name: "Иванов Иван",
  role: "Backend-разработчик",
  tag: "Python · Django",
  photo: "team/ivanov/photo.jpg"
},
```

`slug` — имя вашей папки. После этого вы появитесь на странице «Состав»
и в превью на главной.

## Шаг 7. Проверьте

Откройте `team/ivanov/index.html` в браузере: имя, фото, навыки и
кнопки контактов должны быть на месте. Готово — присылайте изменения
старосте или добавляйте в общий репозиторий.

## Пример

Заполненная карточка: `team/krokhin/index.html`.
