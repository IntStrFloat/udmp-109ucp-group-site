# Сайт учебной группы УДМП-109уцп

Статический сайт группы: главная, общая информация и персональные
карточки студентов. Чистые HTML, CSS и немного ванильного JavaScript —
без фреймворков, сборки и зависимостей.

## Как открыть

Двойной клик по `index.html` — сайт целиком работает с диска.
Либо локальный сервер:

```sh
python3 -m http.server
```

и открыть http://localhost:8000

## Структура

```text
group/
├── index.html              главная
├── info/index.html         общая информация о группе
├── team/index.html         состав группы
├── team/krokhin/           пример заполненной карточки
├── team/_template/         шаблон карточки + инструкция
└── assets/
    ├── css/                tokens, layout, components, card
    ├── js/                components, roster, card
    └── img/               логотип и фото
```

## Как добавить свою карточку

Кратко: скопировать `team/_template`, заполнить анкету в конце
`index.html`, добавить строку в `assets/js/roster.js`.
Подробно — `team/_template/ЗАПОЛНЕНИЕ-КАРТОЧКИ.md`.

## Заглушки, которые надо заполнить

Ищите слово «заполнить»:

- `index.html` — куратор, староста, число студентов (блок «Факты о группе»);
- `info/index.html` — куратор, староста, общий чат.

## Технические заметки

- Пути шапки и подвала строятся от `<meta name="site-root">`,
  поэтому страницы можно класть на любую глубину папок.
- `assets/js/roster.js` — единственное место со списком состава;
  и главная, и страница «Состав» рисуются из него.
- Анкета персональной карточки — блок
  `<script type="application/json" data-student>` в конце страницы;
  собирает её скрипт `assets/js/card.js`.
- Свои стили и библиотеки (jQuery и др.) подключаются в слотах
  внутри `team/_template/index.html` — общие скрипты ванильные,
  конфликтов с `$` и другими глобальными переменными нет.
